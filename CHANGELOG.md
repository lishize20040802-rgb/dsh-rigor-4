# Changelog / 发布记录

## 0.2.0

- Optional strategies record solution alternatives, technology versions and probes, step dependencies and replanning conditions. Explore and technical child roles provide focused investigation; declared risk determines required review depth.
- Acceptance checks link recorded commands to hashed local reports and tested files. Performance checks evaluate samples against declared numeric thresholds. Completion requires current passing checks and reviews briefed after the latest check evidence.
- Strategy help and role instructions load on demand. Standing guidance plus six tools' names, descriptions and standard input schemas use about 26% fewer UTF-8 bytes than 0.1.3 under the same scope; this is not a token or model-quality benchmark.
- Strategy and validation metadata persist within format 2 / shape 2. Existing records are preserved. Native contract verification remains DSH 0.1.5-rc.2, with no new external npm runtime dependencies.

中文：

- 新增可选策略，记录候选方案、技术版本与待执行探针、步骤依赖和重规划条件；探索与技术子任务负责专项调查，声明风险决定所需审阅深度。
- 验收检查关联实际命令、带哈希的本地报告和被测文件；性能检查按声明阈值核对样本。完成前需要当前检查通过，且审阅简报晚于最新检查证据。
- 策略帮助和角色说明按需提供；常驻纪律与六工具名称、描述、标准输入 schema 的 UTF-8 体积同口径约缩减 26%，不代表 token 或模型能力评测。
- format 2 / shape 2 保持不变，保留旧记录并持久化策略和验证元数据。原生契约核对版本仍为 DSH 0.1.5-rc.2，没有新增外部 npm 运行依赖。

Use `npx --yes dsh-rigor-4@0.2.0 setup` to install or upgrade. Existing differing preset files are preserved; `--replace-presets` explicitly replaces them. Restart DSH after installation. / 使用该命令安装或升级；已有不同内容的预设默认保留，显式传入 `--replace-presets` 才会覆盖。安装后重启 DSH。
